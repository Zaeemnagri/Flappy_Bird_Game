# Flappy_Bird_Game
A simple Flappy Bird cGame made in C++ using the Raylib library, featuring basic physics, obstacles, and score tracking.
Flappy Bird Clone in C++ using Raylib
=====================================

This is a simple Flappy Bird clone developed in C++ using the Raylib library. The project demonstrates basic game development concepts such as gravity, collision detection, and score tracking.

Features:
---------
- Bird movement with gravity and flap control
- Randomly generated pipe obstacles
- Collision detection and game-over condition
- Score tracking system

Requirements:
-------------
- C++ Compiler (g++)
- Raylib library installed (https://www.raylib.com/)

How to Compile and Run:
------------------------
g++ -o flappy main.cpp -lraylib -lGL -lm -lpthread -ldl -lrt -lX11
./flappy

Controls:
---------
Spacebar - Flap / Jump
Esc      - Exit the game
